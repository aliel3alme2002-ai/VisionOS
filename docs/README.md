# Documentation Directory

The `docs/` directory serves as the technical repository for architectural decision records (ADRs), research sprints, engineering guidelines, system design specifications, and API specifications for VisionOS.

## Subdirectories

- **[`architecture`](./architecture/system-design.md)**: Official System Architecture & Design Specification.
- **[`research-sprint`](./research-sprint/catalog.md)**: Technical evaluation of NVR & Vision Stack platforms (Frigate vs Shinobi vs ZoneMinder).
- **[`roadmap`](./roadmap/README.md)**: Product development milestone roadmap and phase timelines.
- **[`adr`](./adr/README.md)**: Architectural Decision Records (ADRs).
- **[`api`](./api/README.md)**: OpenAPI and gRPC contract specifications.
- **[`product`](./product/README.md)**: Product Requirement Documents (PRDs) and user stories.
