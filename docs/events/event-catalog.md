# VisionOS Domain Event Catalog

This document indexes all official event types emitted across the **VisionOS** platform.

---

## 1. Domain Event Index

| Event Type Name | Category | Primary Topic Pattern | Description |
| :--- | :--- | :--- | :--- |
| `vision.edge.connected` | Edge Lifecycle | `vision/{tenantId}/{edgeId}/edge/status` | Edge Box container runtime established connection. |
| `vision.edge.disconnected` | Edge Lifecycle | `vision/{tenantId}/{edgeId}/edge/status` | Edge Box lost connection or shut down cleanly. |
| `vision.edge.heartbeat` | Edge Telemetry | `vision/{tenantId}/{edgeId}/edge/heartbeat` | Periodic hardware CPU/GPU and memory check-in. |
| `vision.edge.status.changed` | Edge State | `vision/{tenantId}/{edgeId}/edge/status` | Edge Box state shifted (e.g. `ONLINE` to `DEGRADED`). |
| `vision.camera.connected` | Camera Ingestion | `vision/{tenantId}/{edgeId}/camera/{cameraId}/status` | IP Camera RTSP feed connected to Frigate. |
| `vision.camera.disconnected` | Camera Ingestion | `vision/{tenantId}/{edgeId}/camera/{cameraId}/status` | IP Camera RTSP feed lost connectivity. |
| `vision.camera.snapshot.created` | Camera Frame | `vision/{tenantId}/{edgeId}/camera/{cameraId}/snapshots` | Periodic frame snapshot image emitted. |
| `vision.camera.health.changed` | Camera Health | `vision/{tenantId}/{edgeId}/camera/{cameraId}/health` | Camera stream FPS or dropped frame metric changed. |
| `vision.event.created` | Vision AI | `vision/{tenantId}/{edgeId}/events` | Raw computer vision object detection observation. |
| `vision.rule.triggered` | Policy Engine | `vision/{tenantId}/{edgeId}/events` | Policy threshold condition matched (e.g. dwell time > 15s). |
| `vision.alert.created` | Life-Safety | `vision/{tenantId}/{edgeId}/alerts` | Incident alert generated (`CRITICAL`, `LIFE_SAFETY`). |
| `vision.alert.updated` | Incident Workflow| `vision/{tenantId}/{edgeId}/alerts` | Alert acknowledged or assigned by operator. |
| `vision.alert.resolved` | Incident Workflow| `vision/{tenantId}/{edgeId}/alerts` | Alert marked resolved or cleared. |
| `vision.notification.sent` | Communication | `vision/{tenantId}/{edgeId}/notifications` | Notification successfully sent via SMS/Push/WS. |
| `vision.notification.failed` | Communication | `vision/{tenantId}/{edgeId}/notifications` | Notification dispatch attempt failed. |
| `vision.license.updated` | Entitlement | `vision/system/licenses` | License key renewed or camera quota updated. |
| `vision.license.expiring` | Entitlement | `vision/system/licenses` | License key within 14-day expiration window. |

## 2. Event Category Breakdown

### 2.1 Edge & Camera Infrastructure Events
Focus on hardware connectivity, RTSP stream health, and node availability.

### 2.2 Computer Vision & AI Events
Generated by Frigate NVR and custom deep learning inference containers (`ai-custom-service`).

### 2.3 Policy & Alert Life-Safety Events
High-priority events evaluated by `pipeline-service` that drive immediate local siren relays and dashboard alerts.

### 2.4 Communication & Entitlement Events
System-level notifications and platform entitlement enforcement.
