# Product Documentation (`docs/product`)

This directory stores Product Requirement Documents (PRDs), feature functional specs, and user story maps for VisionOS.

## Specifications

- **`prd-drowning-detection.md`**: Functional requirements and safety response SLAs for swimming pool drowning alert features.
- **`prd-erp-sync.md`**: Functional requirements for physical event mapping to SAP/Odoo transactions.
- **`prd-license-management.md`**: Entitlement policies, quota limits, and offline license key management.
